# ゆめつきクエスト：初回開催前の未確定事項

本番の開催を作成・公開する前に、管理者が `/admin/quest` で以下を確定する。

- 開催名・説明・画像・開始／終了日時と、参加対象・限定コード・対象X一覧。
- 通常サイコロの配布方式と日時。１開催で最大14回。
- イベント勝利・管理者付与の救済を使うか、付与元・利用条件・試算上の保有率。
- 星ポイント・レベル・評価境界・達成率表示の確定値。新規作成時の推奨初期値だけで確定した扱いにしない。
- 実際の配布・救済条件と分岐／抜け道の選択方針を含む14回の分布試算。目標は最上位２％以下、上位約８％、中間約50％、下位約40％。全参加者の実績分布とは区別する。
- 初回の案内・ランキングの運用と、トップメニューの公開範囲を切り替える時期。メニューの公開範囲と開催の参加条件は別々に設定する。

保存した設定で試算し、検討記録と確認を経て公開する。通常ポイント・発送物の配布や、他企画の参加条件を自動的に変更する指示ではない。
